## LinkedIn

Everyone is building AI agents. Almost nobody is building the operations layer to run them.

I'm building Shamar (שמר — Hebrew, "to keep, guard, watch over"): open-source mission control for humans, agents, models, tools, and autonomous work. Think of it as the missing ops console — agent registry, event logging, usage tracking, and a live dashboard. Local-first, provider-neutral, Apache 2.0 licensed.

The MVP is live today. You can try a working demo right in your browser — no signup, no install:
https://shamar-site.asjames18.workers.dev/demo

If you've ever had agents running in the background and no real idea what they were doing, what they were calling, or what it was costing — that's the problem Shamar exists to solve.

It's early, and it's open source on purpose. If you're a builder who wants to work on infrastructure for the agent era, I'd welcome the help. Good first issues going up this week:
https://github.com/asjames18/Shamar
